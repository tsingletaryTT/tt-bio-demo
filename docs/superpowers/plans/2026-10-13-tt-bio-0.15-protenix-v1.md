# tt-bio 0.15.2 and protenix-v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pin tt-bio 0.15.2 and move the booth from `protenix-v2` (weights no longer downloadable) to `protenix-v1` (Apache-2.0, downloads), with every printed number re-measured on v1.

**Architecture:** One model-id change across runner, UI defaults, weights provisioning (source install, .deb, doctor, preflight) and copy. The v1 checkpoint lives at `<cache>/protenix/model_v0.5.0.pt`, a subdirectory, so the two places that assume a flat `<cache>/<file>` path (the postinst's sha table and doctor's filesystem fallback) change shape and not just a name. A spike on hardware runs first because two earlier bumps broke on API shapes an import check could not see.

**Tech Stack:** Python 3.12, GTK4, tt-bio 0.15.2 (ttnn 0.68.0), bash, Debian packaging, pytest via `scripts/test.sh`, gozer hardware leases.

**Spec:** `docs/superpowers/specs/2026-10-13-tt-bio-0.15-protenix-v1-design.md`

## Global Constraints

- Default branch is `main`; work stays on `tt-bio-latest-upgrade`.
- tt-bio is pinned to a release tag (`TT_BIO_VERSION` in `scripts/setup-venvs.sh`), never `main`.
- Use the project venvs and `scripts/test.sh`, never bare `python3`.
- Every command that opens `/dev/tenstorrent/*` runs under a gozer lease: `gozer run --chips 1 --who "claude:tt-bio-demo" --reason "<why>" -- <cmd>`. `import ttnn` / `import tt_bio.protenix` counts. Check packages with `importlib.util.find_spec`.
- Long diagnostic hardware runs go in the background (`run_in_background`), never foreground, so a tool timeout cannot kill a fold mid-DMA.
- Never `tt-smi -r` by hand. `gozer release` resets the chips it held.
- Filter long output by content (`grep`), never by position (`tail`/`head`): tt-metal teardown prints thousands of leak lines.
- Nothing is printed to a visitor, README, site or one-pager unless this branch measured it on v1. A target nobody has folded shows "not yet timed".
- No stack traces in the UI.
- Writing for people: plain English, no "X, not Y" framing, no aphoristic closers. Sweep drafts for `, not `, `rather than`, `instead of`, `reads as`, `honest`, `the one`, `which is why`, `This is what`.
- A test that has never been seen to fail is a claim. Every task that adds a guard re-introduces the bug, watches it go red, restores it.
- Version bump with each change: `debian/changelog` and the handout PDF rebuild (`docs/onepager/build.sh`, then look at it).
- Weights cache is derived in exactly two places (`runner/env.py:weights_cache`, `scripts/weights-cache.sh`). Do not add a third.

## Review Focus

1. A cache holding v2 (`protenix-v2.pt`) but no v1: preflight and doctor must say v1 is missing, with the v1 download command, and must not treat v2 as satisfying the booth.
2. `$TT_BIO_PROTENIX_V1` / `$PROTENIX_V1_CKPT` relocate the checkpoint: preflight and doctor honour it (use `weights.resolve`, not a built path).
3. A truncated v1 file (size below the floor) is reported as truncated, not as ok and not as missing.
4. An old playlist or client message naming `model: protenix-v2` degrades to a presentable refusal, not a traceback and not a silent fold on v1 under the old name.
5. A target that fails on v1 during measurement is recorded and skipped, not hidden and not fatal to the other six.

# $SCRATCH/spike_v1.py  -- throwaway. Runs ONE real v1 fold of Trp-cage and

import time, logging, sys
sys.path.insert(0, "/home/ttuser/code/tt-bio-demo")
from runner import folder as F

events = []
orig_load = F.Folder.load

def load_v1(self):
    # Spike only: swap the model id the load() guard and fetch() read.
    import inspect, textwrap
    src = inspect.getsource(orig_load).replace('"protenix-v2"', '"protenix-v1"')
    ns = {}

    return ns["load"](self)

F.Folder.load = load_v1
f = F.Folder(device_id=0, model="protenix-v1")
t0 = time.monotonic(); f.load(); print("load_s", round(time.monotonic() - t0, 2))
